# Football Legends

Jeux de foot entre potes, chacun sur son téléphone : un code de salon, des manches, du débat.

- **Un joueur par saison** : 11 manches, un poste et une saison de Premier League. On cite un joueur de mémoire.
- **Plus ou moins** : le joueur suivant a-t-il marqué plus ou moins de buts en PL ?

Le jeu tient dans une seule page, `index.html`, publiée avec GitHub Pages. Le temps réel passe par Supabase : renseigne `SUPABASE_URL` et `SUPABASE_KEY` en haut du script. Si ces deux valeurs sont vides, le jeu tourne en mode test entre plusieurs onglets du même navigateur.
